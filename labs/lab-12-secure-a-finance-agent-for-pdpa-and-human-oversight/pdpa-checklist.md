# PDPA checklist for a finance AI agent

Singapore Personal Data Protection Act. Complete before any agent handling personal data is published.

- [ ] **Purpose limitation** - the AI use is consistent with why the data was collected
- [ ] **Consent / notification** - obtained or given where required
- [ ] **Minimisation** - the agent uses the least personal data that works
- [ ] **Accuracy** - there is a route to correct anything the agent states wrongly about a person
- [ ] **Protection** - access through the agent matches existing entitlements, and no more
- [ ] **Retention limitation** - prompt, output and log retention is defined and owned
- [ ] **Transfer limitation** - no personal data leaves the tenant or the jurisdiction
- [ ] **Accountability** - a named Data Protection Officer has reviewed and signed off

Restricted data - payroll, NRIC, bank details, credit files - must never be entered into any AI tool,
including approved ones.

Report a suspected breach to the Data Protection Officer within 24 hours.
