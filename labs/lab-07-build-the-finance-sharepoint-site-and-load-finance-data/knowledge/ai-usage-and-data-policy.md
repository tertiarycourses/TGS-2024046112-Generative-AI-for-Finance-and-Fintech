# Northstar Finance — AI Usage and Data Handling Policy

## 1. Purpose
This policy governs how Northstar Finance staff use Microsoft 365 Copilot,
Copilot Studio agents and other AI tools with finance data.

## 2. Data classification
| Class | Examples | AI use |
|---|---|---|
| Public | Published results, press releases | Permitted |
| Internal | Management reports, budgets, policies | Permitted in approved tenant tools |
| Confidential | Customer accounts, contracts, pricing | Approved tools only, with access controls |
| Restricted | Payroll, NRIC, bank details, credit files | **Prohibited** in any AI prompt |

## 3. Prohibited actions
- Pasting Restricted data into any AI tool, including approved ones.
- Using consumer or personal AI accounts for Northstar work.
- Uploading finance data to any tool not on the approved list.
- Publishing an agent without authentication where it can reach internal data.
- Using AI output as evidence without independent verification.

## 4. PDPA obligations
Northstar is subject to Singapore's Personal Data Protection Act. Staff must:
- Use personal data only for the purpose it was collected for.
- Minimise personal data in prompts; aggregate or mask wherever possible.
- Not transfer personal data outside the approved tenant.
- Report any suspected data breach to the Data Protection Officer **within 24 hours**.

The Data Protection Officer is contactable at dpo@northstar.example.

## 5. Verification duty
AI output is a draft until a person verifies it. Every figure in an AI-drafted
report must be traced to an approved source before the report is issued.
The preparer remains accountable for the content of anything they submit.

## 6. Agent governance
Every finance agent must have a named business owner, a documented purpose, a
defined knowledge scope, and an annual review. Agents that are unused for
90 days are retired.

## 7. Human oversight
Material or irreversible decisions require human approval as set out in
POL-FIN-003 Delegation of Authority. An approval gate must be configured so
that inaction results in rejection, never in automatic approval.
